# Customer Shopping Behavior Analysis

A data analytics project focused on analyzing customer shopping patterns, purchase behavior, and business insights using Python, SQL, Excel, and Power BI.

## Project Overview

This project analyzes customer shopping data to understand customer preferences, spending behavior, product demand, and purchasing trends. The goal is to convert raw retail data into meaningful insights that can help businesses improve marketing, pricing, inventory, and customer retention strategies.

## Objectives

- Analyze customer purchase behavior
- Identify top-performing product categories
- Study the impact of discounts and subscriptions
- Segment customers based on age, gender, and purchase frequency
- Build business insights using visualizations and dashboards
